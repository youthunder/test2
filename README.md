# ✈️ SPICE ROUTE FOOD PASSPORT (세계 전통 음식 어순 탐험 여권)

중학교 영어 문장의 핵심 어순(주어 + 동사 + that절 등)을 세계 전통 음식을 여행하며 학습하는 인터랙티브 문장 배열 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

1. **3가지 입장 카테고리 (총 15개 문항)**
   - **👍 찬성 입장 (5문항)**: 한국 김치, 이탈리아 피자, 멕시코 타코, 태국 길거리 음식, 프랑스 코스 요리
   - **⚖️ 중립 입장 (5문항)**: 인도 카레, 일본 낫토, 스페인 타파스, 베트남 쌀국수, 튀르키예 케밥
   - **👎 반대 입장 (5문항)**: 중국 마라 훠궈, 독일 보존 소시지, 영국 피시 앤 칩스, 비위생 길거리 음식, 호화 연회식

2. **의미 단위(구) 단어 조각 배열 인터랙션**
   - 의미 단위(구)로 쪼개진 단어 버튼이 랜덤하게 섞여 제공됩니다.
   - **주어+동사(S+V) 노란색 강조**: 핵심 주어+동사 조각은 스파이스 마켓의 **터메릭 골드(Turmeric Gold)** 색상과 `주어+동사` 뱃지로 시각적으로 강조되어 문장의 뼈대를 쉽게 파악할 수 있습니다.
   - **클릭 기반 배열 및 취소**: 단어 조각을 클릭하면 배열 칸으로 이동하고, 배열 칸의 조각을 다시 클릭하면 즉시 원래 자리로 취소됩니다.

3. **문장 구조 공식 힌트**
   - 각 문항마다 `주어 + 동사 + that + [동명사 주어 + 동사 + 목적어]` 등 맞춤형 영문법 구조 공식과 상세 구문 해설을 제공합니다.

4. **생생한 피드백 & 여권 비자 스탬프**
   - **정답 시**: **바질 그린(Basil Green)** 성공 테두리, 실제 여권 고무 입국 심사 도장이 찍히는 회전 스탬프 애니메이션(`VISA APPROVED`), 경쾌한 효과음 및 축하 꽃가루(Confetti), 원어민 TTS 음성 재생이 작동합니다.
   - **오답 시**: **칠리 레드(Chili Red)** 색상과 함께 카드 전체가 좌우로 흔들리는 Shake 애니메이션과 부드러운 오답음이 출력되어 바로 다시 도전할 수 있습니다.

5. **카테고리별 진행률 & 여권 스탬프북 모달**
   - 카테고리별 푼 문제 수/전체 문제 수 비율을 진행 바(%)와 스텝 도트로 표시합니다.
   - 상단 **스탬프북(0/15)** 버튼을 누르면 15개국 비자 스탬프 수집 현황을 한눈에 볼 수 있습니다.

6. **반응형 디자인 & 스파이스 마켓 테마**
   - 터메릭 골드(#F59E0B), 칠리 레드(#E11D48), 바질 그린(#059669), 빈티지 양피지 및 네이비 여권 커버 질감 적용
   - 모바일, 태블릿, 데스크톱 화면에 최적화된 유동적 레이아웃 지원

## 🚀 실행 방법

### 방법 1: 로컬 웹 서버 실행 (권장)
현재 터미널에서 백그라운드로 로컬 서버가 실행 중입니다. 브라우저 주소창에 다음 주소를 입력하세요:
```
http://localhost:8080/
```

만약 서버를 다시 실행해야 할 경우:
```bash
python -m http.server 8080
```
또는
```bash
npx serve .
```

### 방법 2: 브라우저에서 바로 열기
`index.html` 파일을 더블 클릭하거나 브라우저로 드래그하여 실행할 수도 있습니다.
